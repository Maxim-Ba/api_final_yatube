# api_final

## Описание проекта

Учебный проект YandexPrakticum - разработка backend сервиса по методу api first, цель которго - это получение навыков по разработке API для взаимодействия с другими программами, в часности с frontend приложением. Сервис REST API. В сервисе реализовано:

- регистрация пользователя
- авторизация по JWT
- CRUD операции постов
- подписка на авторов, получение всех подписок
- коментирование постов

## Используемые технологии

- JWT авторизация
- django REST framework
- python
- sqlite

## Установка

- `python -m venv venv` (создание виртуального окружения)
- `source venv/Scripts/acticate` (активация виртуального окружения)
- `pip install -r requirements.txt` (установка зависимостей)
- `cd /yatube_api` (переходим в проект)
- `python manage.py runserver` (запуск сервера)

## Документация

После запуска `runserver`, можно перейти в [документацию](http://localhost:8000/redoc)
