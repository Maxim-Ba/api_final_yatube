# api_final

## Описание

Учебный проект. Используются такие технологии как:

- JWT авторизация
- django REST framework
- python
- sqlite

## Установка

- pip install -r requirements.txt
- python -m venv venv
- source venv/Scripts/acticate
- cd /yatube_api
- python manage.py runserver
- http://127.0.0.1:8000
